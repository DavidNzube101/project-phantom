# Notion Pack — Proposal & Contracts (Nigeria/Lagos)

Import each page into Notion (New Page → Paste). Keep variables in the "Variables" section at the top and duplicate per client.

Pages:
- Proposal (client-facing)
- MSA (legal terms)
- SOW (project-specific)
- Change Order (scope changes)
- Mutual NDA (confidentiality)

Tip: Create a database "Engagements" with properties:
- Client (Title)
- Status (Lead, Active, Paused, Complete)
- Fee (Number, Currency)
- Start Date (Date)
- End Date (Date)
- SOW Link (URL)
- MSA Link (URL)
- Owner (Person)
